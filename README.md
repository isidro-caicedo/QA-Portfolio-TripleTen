# QA-Portfolio-TripleTen

Proyectos de QA Engineering: Testing Manual, validación de APIs con Postman y consultas SQL desarrollados durante el bootcamp de TripleTen.

Este repositorio centraliza las bases analíticas y técnicas de aseguramiento de calidad, demostrando un enfoque riguroso en la prevención de riesgos, diseño de pruebas y validación de datos.

---

 📂 Estructura del Portafolio

1. Pruebas Manuales y Diseño de Pruebas
* **Artefactos:** Matrices de casos de prueba, listas de comprobación (Checklists) y reportes de ejecución en archivos de Excel estructurados.
* **Habilidades:** Análisis de requerimientos, técnicas de diseño de caja negra (partición de equivalencia, análisis de valores límite), y reporteo de defectos críticos en Jira.

2. Testing de APIs (Postman)
* **Artefactos:** Colecciones de Postman para pruebas de integración y funcionales.
* **Habilidades:** Validación de métodos HTTP (GET, POST, PUT, DELETE), verificación de códigos de estado (200, 201, 400, 404), y análisis de estructuras de respuesta JSON.

3. Validación de Bases de Datos (SQL)
* **Artefactos:** Scripts y consultas de bases de datos.
* **Habilidades:** Consultas avanzadas, uniones de tablas (JOINs), agrupaciones (GROUP BY) y filtros para auditar la correcta persistencia e integridad de la información en el backend.



⚙️ Tecnologías y Herramientas
* **Gestión de Pruebas y Defectos:** Jira / Excel
* **Pruebas de API:** Postman
* **Bases de Datos:** SQL (PostgreSQL / MySQL)
* **Control de Versiones:** Git & GitHub
